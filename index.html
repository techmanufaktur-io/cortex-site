Questions, answered.

Does my clipboard data ever leave my Mac?

No. Capture, search, OCR and AI all run locally. The only network access Cortex has is fetching link previews when you copy a URL — and you can turn that off.

What does the AI actually do?

You define “intents” — situations like Invoice or Deal Update with a prompt each. When you run AI on an entry, Cortex detects the matching intent and applies your prompt: extract fields, summarize, translate, reformat. All with Apple’s on-device foundation model.

What are the system requirements?

macOS 26 or later on Apple Silicon. AI features require Apple Intelligence to be enabled; everything else works without it.

Where is my data stored?

As Markdown files (plus attachments) in a folder you control. Point it at iCloud Drive and your library syncs across Macs — no proprietary database involved.

How does the Claude / MCP integration work?

Cortex includes a small MCP server binary. Add one snippet to your Claude Desktop config, and Claude can list, search, read, create and organize entries in your library. It runs locally over stdio.

Is Cortex free?

Right now, yes: the early-bird release is 100% off. And here’s the promise — core functionality is a one-time lifetime purchase, never a subscription. What you get today stays yours. Much further down the road, a subscription may be offered for optional premium add-ons only.
